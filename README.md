## 🚀 Getting Started

### 1. View Locally

Clone the repository and open `index.html` directly in any web browser:

```bash
git clone https://github.com/Mosiuzzaman-bot/mosiuzzaman.git
cd mosiuzzaman
```

Open `index.html` with your browser:
- **Windows:** `start index.html`
- **macOS:** `open index.html`
- **Linux:** `xdg-open index.html`

### 2. Run with a Local Development Server

If you prefer serving via a local HTTP server:

**Using Python:**
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

**Using Node.js (npx serve):**
```bash
npx serve .
```

## 🌐 Deployment

This static site can be hosted on any static hosting platform:

- **GitHub Pages:** Go to repository **Settings** → **Pages** → under *Build and deployment*, set Source to `Deploy from a branch` → choose `main` branch and `/ (root)` folder → click **Save**.
- **Netlify / Vercel / Cloudflare Pages:** Connect the repository for automatic deployments on push.
